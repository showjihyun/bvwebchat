# checkpoints/ — 불변 기록 (커밋 대상)

`harness/phase.py` 가 전이할 때마다 `<RQ>/<ISO>.json` 을 여기에 쓴다. **덮어쓰지 않는다.**

이 디렉터리가 gitignore 되지 않는 이유: 신선한 클론에서 재개가 가능해야 T.04 상태 계약이
성립한다. 체크포인트가 로컬에만 있으면 "다른 머신에서 이어서 한다"가 불가능하고, 그러면
계약이 있다고 주장할 근거가 없다 (`scripts/resume-test.mjs --cold` 가 이것을 채점한다).

반대로 같은 디렉터리의 `phase.json` · `session.json` · `.key` 는 **라이브 커서**라
gitignore 한다. 커밋하면 모든 커밋이 상태 변화로 더러워지고 병합 충돌이 난다.

파일명이 `2026-07-27T02:00:00Z` 가 아니라 `20260727T020000Z` 인 이유: 콜론은 Windows
파일명에 쓸 수 없다. 전체 타임스탬프는 파일 안 `ts` 필드에 있다.
